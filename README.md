# PAPER ROOM v3.4 — 세 편의 논문 협업 예시

이 저장소의 웹 UI는 한국어이며, 공개 논문 샘플 3개를 포함합니다.

- 진행 중: **Cross-Environment LiDAR–Camera Misalignment Detection via Object-Level VLM Assessment**
- 완료: **특징점이 부족한 실내환경에서의 Visual Localization 에 대한 연구**
- 완료: **MARSCalib: Multi-robot, Automatic, Robust, Spherical Target-based Extrinsic Calibration in Field and Extraterrestrial Environments**

각 예시의 실제 논문 이미지·결과 수치를 제공하며, 협업 활동/타임라인/메모/담당자/승인 상태는 *교육용 가상 예시*입니다. 과거 버전 보기와 편집 사본 복원 기능을 제공합니다.

상세한 업로드·배포·검증 방법은 [THREE_PROJECTS_GUIDE_KO.md](THREE_PROJECTS_GUIDE_KO.md)에서 확인하세요.
