# PAPER ROOM 한국어 UI 버전

이 폴더는 PAPER ROOM v3 수업 제출용 예시 프로젝트를 한국어 인터페이스로 변경한 배포 패키지입니다.

## 반영 내용
- 사이드바, 메뉴, 대시보드, 그림·표 목록, 할 일, 기록, 공동저자 초대의 영어 UI 문구를 한국어로 통일
- 새 프로젝트/초대/결과물 추가 모달 및 버전 기록·이전 버전 열람·복원·비교 화면 한국어화
- 예시 OLIVE 프로젝트 제목/작업 제목/결과표 열 이름을 한국어화. 기술 용어와 방법 이름(OLIVE, LiDAR, KITTI, MIL, CSV, LaTeX)은 유지
- 버전 비교에서 JSON 키를 사용자에게 친숙한 한국어 필드명으로 표시하고 현재 버전에도 담당자 필드 포함
- 기존 로그인 없는 초대 링크, 서버 저장, 복제, 댓글, 복원 로그 기능과 API 형식 유지

## 배포 방법
Render 무료 Blueprint 배포는 기존 `SUBMISSION_GUIDE_KO.md`를 참고하세요. 이미 배포한 저장소가 있다면 기존 소스 파일을 이 버전으로 교체하고 다시 배포하세요.
새 서버를 만들 때는 Github에 압축을 푼 파일을 업로드하고 Render에서 New > Blueprint를 선택하세요.
Render Free의 로컬 SQLite는 서버 재시작 후 데이터가 유지되지 않으므로 실제 공동작업 기록의 보존이 필요하면 기존 안내서대로 외부 DB를 연결하세요.

## 로컬 테스트
`python3 tests/test_smoke.py`
`python3 tests/test_versions.py`

중요: 기존 서버에서 생성한 데이터베이스를 사용하는 경우 예시 데이터는 자동으로 다시 생성되지 않습니다. 새로운 배포 또는 새로운 데이터 디렉터리에서는 한글 예시 프로젝트가 자동 등록됩니다. 이미 생성된 개인 프로젝트 데이터는 이 패키지에서 자동으로 재작성하지 않습니다.
