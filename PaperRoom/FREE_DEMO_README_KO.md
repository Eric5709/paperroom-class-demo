# PaperRoom v2 - Render 무료 시연 배포

## 비용
- Render Web Service 플랜: free ($0/월)
- 외부 데이터베이스: 없음
- 디스크: 없음 (무료 인스턴스에 영구 디스크 연결 불가)
- Render의 무료 제공량을 초과하면 대역폭/빌드 사용에 따라 별도 요금이 발생할 수 있으므로 Billing에서 비용 설정 및 사용량을 확인하세요.

## 매우 중요한 데이터 보존 제한
이 배포는 **시연 전용**입니다. Fig/Table 데이터, 초대 링크, 사용자 작업, 업로드 파일은 서버의 임시 SQLite 저장소에 기록됩니다.
Render Free Web Service는 15분 동안 요청이 없으면 휴면하며 재가동/재시작/재배포 과정에서 **모든 임시 데이터가 지워질 수 있습니다**.
수업 제출 전 데이터를 장기간 보관해야 하거나 여러 학생이 지속적으로 협업해야 한다면 **이 구성을 사용하지 마세요**.
무료 영구 저장을 위해 별도 무료 외부 DB/오브젝트 스토리지와 연동하도록 백엔드 수정이 필요합니다.

## 배포 절차
1. ZIP을 풀어 안의 파일을 GitHub repository 최상위에 올립니다.
2. Render Dashboard → New → Blueprint → GitHub repository 선택.
3. `render.yaml`을 인식해 free Web Service가 생성되는 것을 확인합니다.
4. Render에서 안내되는 요금 화면에서 유료 서비스를 절대 선택하지 마세요.
5. 생성된 `https://...onrender.com`으로 시연합니다.

## 작동 조건
- 초대는 이메일 주소를 기록하고 링크를 생성하는 방식이며, 발송 서버 SMTP를 설정하지 않으면 수동 링크 전송입니다.
- 공개 데모 프로젝트는 읽기 전용; 생성한 비공개 프로젝트는 소유자 링크가 접근 권한을 제공합니다.
- 무료 서비스의 SMTP 포트 25, 465, 587은 차단되어 있어 일반 SMTP 전송은 지원되지 않습니다.
